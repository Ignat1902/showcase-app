# RuStore Showcase

Android-приложение для каталога мобильных приложений, выполненное в рамках практического задания. Данные загружаются через Retrofit из локального мок-бэкенда на базе OkHttp interceptor, поэтому приложение работает без внешнего сервера.

## Функциональные возможности

- Онбординг при первом запуске с логотипом RuStore и переходом на витрину.
- Витрина приложений со списком приложений, иконкой, названием, категорией и кратким описанием.
- Экран категорий с количеством приложений в каждой категории.
- Фильтрация витрины по выбранной категории.
- Отдельный экран поиска с автооткрытием клавиатуры и интерактивным поиском по названию.
- Отображение популярных приложений при пустом поисковом результате.
- Карточка приложения с разработчиком, категорией, возрастным рейтингом, описанием и скриншотами.
- Полноэкранный просмотрщик скриншотов с горизонтальным свайпом.
- Pull-to-refresh на основных экранах.
- Состояния загрузки и ошибки для сетевых экранов.

## Сборка и запуск

1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Выбрать конфигурацию `app`.
4. Запустить приложение на эмуляторе или физическом устройстве с Android 8.0+.

Для сборки debug APK из терминала:

```powershell
.\gradlew.bat assembleDebug
```

Готовый APK будет находиться по пути:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Мок-бэкенд

В проекте нет внешнего сервера. Все endpoint-ы (`/apps`, `/apps/{id}`, `/categories`, `/popular`) обрабатываются в `MockBackendInterceptor`, а остальная часть приложения работает так же, как с обычным сетевым API.
